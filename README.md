# Автотесты UI stellar burgers

Проект содержит автотесты для веб-приложения stellar burgers (https://stellarburgers.nomoreparties.site/)

## Структура проекта
Tests/
  -test_login.py # тесты авторизации
  -test_registration.py # тесты регистрации
  -test_navigation.py # тесты переходов, выход из ЛК, конструктор
-data.py # тестовые данные
-locators.py # локаторы для страниц
-utils.py # вспомогательные функции (wait, safe_click)
-conftest.py # фикстуры pytest (browser, registered_user)
-requirements.txt # зависимости проекта
-README.md # документация

### Реализованные тесты
Login
-вход с главной страницы
-вход через «Личный кабинет»
-вход после регистрации
-вход через форму восстановления пароля

Registration
-успешная регистрация нового пользователя
-ошибка при вводе слишком короткого пароля

Navigation
-переход в личный кабинет
-переход обратно в конструктор
-переход по логотипу Stellar Burgers
-выход из аккаунта
-переключение вкладок конструктора («Булки», «Соусы», «Начинки»)

#### Запуск тестов
 pytest -v
